# Localization

Eight locales, one runtime loader.

- Supported: `en kn hi ja ml ta te gu`
- Dictionaries live next to the web app; the loader is generic
  (language-agnostic key lookup with English fallback).
- Dropdown labels are bilingual (`ಕನ್ನಡ / Kannada`-style) so speakers can
  find their language either way.

When a locale ships or gets refined, the release note lands in `releases/`.
